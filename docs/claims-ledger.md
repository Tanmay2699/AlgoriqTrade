## Rules recap

- External statistics: primary source pinned (figure, publication, date)
  before first use; dated in the copy itself.
- Engineering claims: repo-relative receipt; if the receipt moves, the row is
  re-verified, not deleted.
- Prices are never in this ledger or in copy — they render live from
  svc-billing (working rule 3).
